   - Configure multi-module structure: domain, repository, service, controller, common

   - Card entity: id, code, name, issuer, colorHex, iconUrl, isActive

   - Category entity: id, code, name, icon, parentId (self-referencing)

   - CardRepository with findByCode, findAllActive methods

5. Create service layer with business logic:

   - CardService: getAvailableCards, getCardMerchants
   - Implement transaction management with @Transactional
   - Add service layer caching annotations

6. Build RESTful controllers with proper structure:
   - MerchantController: GET /merchants, /merchants/{id}, /merchants/nearby, /merchants/search

   - AuthController: POST /auth/login, /auth/refresh (stub for now)
   - RouteController: POST /routes/calculate (stub for now)
   - Add request/response DTOs with validation
   - Implement global exception handling with @ControllerAdvice

7. Configure cross-cutting concerns:
   - CORS configuration for frontend integration
   - Request/response logging interceptor
   - API versioning setup (URL path versioning)
   - Jackson configuration for JSON serialization
   - Enable compression for responses
