# Subtasks:
## 1. Install and Configure Vitest Test Runner [pending]
### Dependencies: None
### Description: Set up Vitest as the primary test runner with proper TypeScript support, coverage reporting, and jsdom environment for React component testing
### Details:
Install vitest@latest, @vitest/ui, @vitest/coverage-v8, and jsdom as dev dependencies. Create vitest.config.ts in the project root with path aliases matching tsconfig.json, configure test globals, set up jsdom as the test environment, and configure coverage reporting with v8 provider targeting 80% coverage threshold. Include proper exclude patterns for node_modules, .next, and other build directories. Set up test reporters for both terminal and JSON output for CI integration.

## 2. Configure React Testing Library with Custom Utilities [pending]
### Dependencies: 6.1
### Description: Set up React Testing Library with Next.js specific utilities, custom render functions, and global test setup including jest-dom matchers
### Details:
Install @testing-library/react, @testing-library/jest-dom, @testing-library/user-event, and @testing-library/react-hooks. Create test/setup.ts that extends default render with providers (NextRouter, Zustand stores), configure jest-dom matchers globally, and set up afterEach cleanup. Create test/utils/index.tsx with custom render function wrapping components with necessary providers. Create specific mock utilities for Next.js router (useRouter, usePathname, useSearchParams) and Naver Maps API (Map, Marker, InfoWindow constructors). Set up test-utils for common testing patterns like waitForLoadingToFinish.

## 3. Set Up MSW for API Mocking in Tests [pending]
### Dependencies: 6.2
### Description: Integrate Mock Service Worker with the testing environment to reuse the mock API handlers from task 5 for consistent test data
### Details:
Create test/mocks/server.ts that imports handlers from the existing MSW setup (task 5), configure setupServer for Node.js test environment. Add beforeAll, afterEach, and afterAll hooks in test/setup.ts to start server, reset handlers, and close server. Create test/mocks/test-data.ts with specific test fixtures for merchants, cards, and routes that can override default mock responses. Implement utility functions for customizing mock responses per test (e.g., mockSearchResponse, mockMerchantDetails). Ensure mock service worker intercepts all API calls during tests without requiring changes to application code.

## 4. Install and Configure Playwright for E2E Testing [pending]
### Dependencies: None
### Description: Set up Playwright with multi-browser support, mobile viewports, and visual regression testing capabilities for comprehensive E2E testing
### Details:
Install @playwright/test as dev dependency and run 'npx playwright install' to download browser binaries. Create playwright.config.ts with projects for Chrome, Firefox, and Safari (both desktop and mobile viewports). Configure baseURL to use localhost:3000, set up test timeout of 30 seconds, configure screenshot on failure, and enable video recording for debugging. Set up visual regression testing with toHaveScreenshot assertions and threshold configurations. Create playwright/.gitignore to exclude test results and screenshots from version control. Configure parallel test execution with appropriate worker count based on CI environment.

## 5. Create Test File Structure and Write Component Tests [pending]
### Dependencies: 6.2, 6.3

Write comprehensive tests for MapContainer covering marker rendering with different zoom levels, marker clustering behavior, and info window interactions. Test SearchBar with debouncing logic, autocomplete dropdown, loading states, and error handling. Create FilterPanel tests validating filter state management, URL synchronization, and filter persistence. Write MerchantCard tests checking rendering with different card types (CHILD_MEAL, CULTURE_NURI), proper styling application, and click interactions. Each test file should achieve >80% coverage for its component.

## 6. Set Up CI/CD Pipeline and Development Tools [pending]
### Dependencies: 6.1, 6.4, 6.5
### Description: Configure automated testing in CI/CD pipeline with GitHub Actions, add pre-commit hooks, and create npm scripts for different testing scenarios
### Details:
Add npm scripts to package.json: 'test' for Vitest, 'test:ui' for Vitest UI mode, 'test:coverage' for coverage report, 'test:e2e' for Playwright, 'test:e2e:ui' for Playwright UI mode.
